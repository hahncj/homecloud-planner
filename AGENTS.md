# Agent Roles

Use these roles as perspectives, not independent autonomous agents.

## Product and architecture

Protect project scope, modular-monolith boundaries, and long-term maintainability.

## Backend

Own Spring Boot APIs, domain behavior, persistence, migrations, validation, and backend tests.

## Frontend

Own React pages, forms, API integration, accessibility, loading states, and frontend tests.

## Database

Review schema design, indexes, constraints, migrations, and data lifecycle.

## DevOps

Own Docker Compose, CI, environment configuration, health checks, and repeatable local startup.

## Quality

Review security, edge cases, test coverage, error handling, and documentation.
